## Featured Project

### VulnTrace

**Vulnerability Analysis & Prioritization Platform**

VulnTrace aims to go beyond simply listing CVEs by determining whether vulnerable dependencies are **actually used**, **reachable**, and **worth prioritizing** in a real application.

- Designed as a **TypeScript-first Monorepo**
- Initial analysis target: **Java / Spring Boot / Maven**
- Maven dependency analysis and **CycloneDX SBOM** generation
- Vulnerability matching using **OSV**
- **React Dashboard / CLI Report**
- Expanding toward Source Usage, Reachability, and Risk Scoring analysis

**Tech Stack**  
`TypeScript` `React` `Fastify` `PostgreSQL` `Prisma` `CycloneDX` `OSV` `Maven`

Currently implemented through **Phase 3**.

For detailed architecture, implementation notes, and usage instructions, visit the repository below.
